Meta Search Engines
AsiaYeah 中文Meta search提供搜尋引擎功能及書藉價格查詢。
All-in-One Search
http://www.allonesearch.com
AskJeeves
http://www.askjeeves.com 
Searches six leading engines, plus its own "knowledgebase" of six million answers. Uses natural language,returns results page with a group of "frequently asked questions" and answers that might fit your query, then shows a traditional hit list of results. For my test search, the questions were so far from the topic of my query as to be ridiculous. It does not de-dup results or rank results.
Beaucoup Search Engines 
http://www.beaucoup.com
Primarily a "mega page" of links listing many general and topic-specific search engines by categories. One link takes the viewer to a second page that offers search boxes to search 14 search engines separately.
BigHub.com
http://thebighub.com
Copernic
Copernic是目前最受歡迎的免費下載型mata search engines, 在利用Copernic之前,需先到Copernic( http://www.copernic.com)下載Copernic 2000 plus軟體,免費下載的版本只能查詢web,newsgroups, e-mail address,其他類型資料查詢就必須付費買軟體.
Cyber411 
http://cyber411.com 
Searches 16 engines, including DejaNews; searcher can check-box select the engines to search. Reformulates the query to the target engines' search syntax; groups results by search engine and removes duplicates.
Debriefing 
http://www.debriefing.com
Searches seven major engines, removes duplicates, and ranks results. The Advanced Search feature allows searchers to "search within a site" by specifying a URL.
Dogpile 
http://www.dogpile.com 
One of the oldest and most favored metas, Dogpile searches more than 25 engines, but it searches them three at a time as requested by the searcher. Choices for search sources include the Web, Usenet, FTP, newswires, business news, quotes, weather, white and yellow pages, etc. Results are not de-duped.
FinderSeeker
http://www.finderseeker.com  
A search engine that finds search engines, specifically topical engines, such as automotive, employment, hobbies, financial, etc.  Little help or direction is available at the site; best used as a source to find subject-specific search engines, and not as a meta engine.
Find-It!
http://www.itools.com/find-it/find-it.html
Highway61
http://www.highway61.com 
At a site that is a bit funky, this meta searches five engines and interprets search query into native syntax for each engine. Can set timeouts, and ranks and de-dups results, which are displayed in an inelegant output format.
InFind(InferenceFind)
http://www.infind.com 
Searches six engines in parallel (simultaneously), and "clusters" results; removes duplicates. Results are displayed in a brief list with four- to six-word titles, and no URLs, descriptions, or indication as to which engines they came from. Can be configured to search additional engines.
Internet Sleuth
http://www.isleuth.com 
Searches each of six major search engines sequentially, showing results from one, then moving on to search the next. Offers a good selection of subject categories that can be searched by choosing specific sites from topical screens. Best used to find subject-specific sites or engines.
Intelliseek
http://www.intelliseek.com/index.htm
Ixquick
http://ixquick.com
Mamma
http://www.mamma.com 
Touted as the "mother of search engines," Mamma searches seven engines simultaneously, and reformats queries in the appropriate syntax for each. The list of engines is not immediately apparent; it is hidden under the Power Search option, where the searcher can select which engines to search.
MetaCrawler
http://www.metacrawler.com
http://www.go2net.com/search.html
Owned now by Go2Net, this meta searches nine engines, ranks results, and tailors the search query for each engines' syntax. The results are mixed by engine and show which engine they came from.
Metafind
http://www.metafind.com 
This minimal screen displays a link to Dogpile, but not much else, including no documentation or information about which engines it searches. There are timeout and sort functions, and the ranked results display the source search engine.
MetaGopher
http://www.metagopher.com 
Searches eight search engines, best used by selecting the Customize option to select which engines to search, preferred display options, etc.
Metasearch
http://metasearch.com
ProFusion
http://www.profusion.com 
Choose all or some of nine search engines using checkboxes, offers choice of Boolean. Offers option to let ProFusion select the "best 3" or the "fastest 3" engines for a search.
SavvySearch
http://www.savvysearch.com
Searches up to 100 engines, and on the selection screen it strongly recommends against searching all the engines. Offers choice to search an engine first, last, or in the middle of the search. Selection of engines can be saved for future use. Also offers good choices for use of topical/subject search engines.
Search.com
http://www.search.com
Search Spaniel
http://www.searchspaniel.com 
A poor take-off on Dogpile, Search Spaniel needs obedience training. Checkboxes offer a choice of eight search engines, but the results open separate windows or frames (your choice) to each engine's results screen, creating a very messy desktop.
Starting Point
http://www.stpt.com 
Best feature is ability to search within subject categories, such as entertainment, etc.
SuperSeekWeb Search
http://www.super-seek.com/super-seek.htm  
Searches 12 search engines selected with checkboxes. Like Search Spaniel, it opens windows for each engine searched. The opening screen offers clicks to some topical screens and engines, including a link to a good page of meta search engines. Best used for topical and specialty searching.
Verio Metasearch
http://search.verio.net 
Searches eight engines; retrieves ten hits from each one; unique feature is ability to weight the engines, with the results delivered in a table format showing the rank and score for each hit.
