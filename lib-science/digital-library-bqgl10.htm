國外數字圖書館資源綜述

李洪

深圳大學圖書館　深圳 518060

〔摘要〕 介紹當前國外數字圖書館資源的主要類型，包括全文資源、二次文獻和書目訊息、多媒體資源及網頁、通訊閘等，具體介紹各類資料的種類；分析各類型資源的特點；重點論述數字圖書館各類型資源在國外的發展現狀。

〔關鍵詞〕 數字圖書館　資源　國外

〔分類號〕 G250.76

　　數字圖書館源起於20世紀80年代末，90年代後隨互連網的廣泛應用而蓬勃發展，進入21 世紀, 數字圖書館已成為現代圖書館的重要發展方向，各國都加快了數字圖書館的建設步伐。

1　國外數字圖書館資源的類型

　　目前數字圖書館的服務內容及形式因其服務宗旨及用戶需求而形式各異。以加拿大麥姬兒大學圖書館 ( http://www.library.mcgill.ca/ ) 為例，其數字資源包括︰電子圖書；電子期刊；數據庫；保留資料（即e-reserves，包含課程大綱、講稿和課件等)；線上檢索目錄；電子辭典、百科全書、指南、手冊以及其他各種電子參考工具；各類電子資源的字順目錄及主題索引等。這些類別代表了學術型數字圖書館資源的基本類型。

　　公共型數字圖書館為滿足用戶的不同需求，其數字資源的範圍通常很廣。例如美國紐約公共數字圖書館 ( http://www.nypl.org/index.html )，除了擁有上述各類數字資源之外，還擁有地圖、照片、圖片、繪畫、音樂等電子音像資料以及報紙、剪報等電子文本資源。

　　近年來，一些國家政府機構啟動了資源數字化項目。例如，1995年美國國會圖書館啟動的國家數字圖書館計畫（National Digital Library Program, NDLP）由15所研究圖書館和檔案館參與項目建設；其目標是將國會圖書館和其他公共圖書館、研究圖書館中的繪畫、圖書、音樂、手稿、照片、視頻、音頻等眾多反映美國歷史、文化的史實性文獻轉換成數字資源；目前它已擁有100多個歷史資源庫，數字作品超過750萬件。又如法蘭西國家圖書館的資源數字化項目，包括1萬本圖書的文本全文、10萬本圖書的掃描影像、30萬張圖片和3 000件錄音資料。此外，還包括上千件14世紀的精美手稿。

2　國外數字圖書館各類型資源的特點及發展狀況

2.1全文資源

2.1.1學術性電子期刊20世紀90年代初，全球一些知名的出版社開始將其出版的期刊電子化。目前，大多數電子期刊還都有其相應的印刷版，兩者內容有時會有出入，有些電子期刊的電子版比印刷版的內容更豐富。

　　很多數字圖書館將電子期刊作為其館藏的重要組成部分。由於電子期刊出版物往往只賦予用戶使用權，而不是擁有權，這就帶來了一個問題︰一旦數字圖書館停購某電子期刊，對其以往的卷期往往也就沒有使用權了，而印刷版期刊則不存在這個問題。

　　國外學術性電子期刊的主要供應商有以下10個︰

　　●EBSCO ( http://www.ebsco.com  )──美國電子全文學術期刊供應商，擁有100余個數據庫，提供近萬種電子期刊全文服務。

　　●ProQuest Information and Learning（ http://www.il.proquest.com ）──原UMI公司，美國訊息收集、組織和發行商，提供從縮微品到數字化的多種形式的產品，與全球9 000多家出版社有合作關係。

　　●Emerald ( http://www.emeraldinsight.com )──英國出版商，提供100多種管理學和圖書資訊學領域的英文電子期刊服務；

　　●Ingenta ( http://www.ingenta.com )──英國出版商，提供約5 500種電子期刊服務。

　　●JSTOR ( http://www.jstor.org )──美國出版商。JSTOR全名為Journal Storage，是一個對過期期刊進行數字化的非營利性機構，提供藝術、人文和社會科學領域的約322種電子期刊服務。

　　●Elsevier( http://www.elsevier.com )──總部設在荷蘭的歷史悠久的跨國科學出版公司。近年來，該公司收購了許多出版公司，包括美國的Ei公司, Harcourt 公司 (包括Academic Press)，同時該公司將其出版的期刊全部數字化，建立了ScienceDirect全文數據庫(http://www.sciencedirect.com)，提供科技領域的約1 800種電子期刊。

　　●Swets Blackwell ( http://www.swetsblackwell.com )──荷蘭及英國出版商，提供26萬種紙本及電子期刊服務。

　　●Kluwer Acdemic Publisher ( http://www.kluwer.nl )──荷蘭學術出版商。Kluwer Online是Kluwer出版的700余種期刊的網路版。

　　●Springer-Verlag ( http://www.springer.de )──德國科技出版集團, 透過SpringerLink系統提供學術期刊及電子圖書的線上服務。目前共提供439種全文電子期刊。

　　●John Wiley Sons ( http://www.wiley.com  )──美國學術出版機構，出版超過400種的期刊，目前全文線上期刊共有363種。

2.1.2開放式著作檢索、發表及存檔數據庫由於電子期刊的商業化，學人發表文章以及圖書館購買期刊花費不菲，於是有人倡導“開放式檢索”，這樣學人和機構可以在一個開放式數據庫中免費發表、檢索及獲取有價值的學術成果。

　　一些數字圖書館開始發布其內部學術著作，並提供其他開放式數據庫的鏈接。例如澳洲昆士蘭大學數字圖書館 ( http://www.library.uq.edu.au ) 的 “Gateways to eprint” 中可看到本校師生的研究成果（包括未發表及已正式發表的作品）以及與其他類似數據庫的鏈接。

　　FindArticles ( http://www.findarticles.com ) 是由商業出版商建立的數據庫，內容包括約900多種出版物的500萬篇文獻。用戶可以免費訪問和使用部分文章。

　　相關的檢索工具也在不斷發展之中，例如，使用美國Michigan大學數字圖書館開發展的OAIster檢索工具( http://www.oaister.org )，可以在全球450多所科研機構的開放式數據庫中檢索到約52萬多條記錄。

2.1.3電子圖書早在1971年，Michael Hart即把一些對全人類而言有一定意義的書籍輸入計算機，放在網路上供人們免費閱讀和下載，這項計畫被命名為古騰堡項目（Project Gutenberg），堪稱電子圖書透過網路進行傳播的開端。現下，古騰堡項目在美國、澳洲、丹麥、德國、墨西哥和南非均設有網站（ http://www.gutenberg.org ），有超過1 5萬本電子圖書可供免費下載和閱讀，已成為互聯網上最大的免費電子圖書的生產者。這些電子圖書由數百名志願者加工而成，除了英文圖書之外，還包含中、法、德、日、俄、荷蘭、西班牙、世界語等40余種語種的圖書。類別有文學、宗教作品及參考工具書（年鑒、百科全書和辭典），其中大多數是在美國不受版權限制的文學著作（如莎士比亞著作、愛麗斯夢遊仙境等名著）。

　　電子圖書是許多數字圖書館的重要資源。與紙本圖書相比，電子圖書主要有以下優點︰包括圖像、圖表、聲音、動畫；能進行全文檢索；電子圖書中的每個單字都與一本詞典連接(只要雙擊電子書中的任一單字，讀者馬上便能看到那個單字的定義)；能多用戶同時使用和檢索；可進行個性化設定（如My Favorite、My Library），提供書簽和註釋功能；館際互借，傳遞速度快；不佔用物理儲存空間，因而能解決書架擁擠的問題；比紙本書價格低廉。

　　國外主要的電子書商及電子書有9個。

　　●Macmillan ( http://www.macmillan.com )︰成立於1843年，是一家全球性的出版公司，業務範圍覆蓋70余個國家。主要涉及教育出版，學術出版，科學、技術和醫學出版，文學作品出版，出版服務5個領域。

　　●Oxford Reference Online ( http://oxfordreference.com )︰收錄了牛津大學出版社所有學科130種以上之字典、辭典與百科全書。含多種查詢功能，每個詞彙有鏈接以供互為參照。另含有超過1 000個網站的鏈接，以作為線上補充參考資源。

　　●Xrefer ( http://www.xrefer.com )︰ 提供來自36個世界頂級出版社的167部參考書，為圖書館和訊息中心提供世界上最大的線上參考服務──Xreferplus。

　　●Netlibrary（ http://www.netlibrary.com ）︰為OCLC旗下之電子書數據庫，收錄來自300多個出版商的各個學科領域的7萬余冊學術性電子書。

　　●ebrary（ http://www.ebrary.com ）︰由McGraw-Hill Companies，Pearson plc和Random House Ventures 三家出版公司共同投資組建。整合了來自200多家學術、商業和專業出版商的威權圖書和文獻，包含商業經濟、計算機技術及工程、人文、生命及自然科學、社會及行為科學五大類，其中學術類收藏中包含了2萬多冊圖書。

　　●Springer( http://www.springerlink.com/ )︰出版科技類電子叢書，截止到2003年8月，已出版20種叢書系列、共約2 000冊電子圖書。還出版了計算科學、數學、工程、地球、環境、物理學方面的重要電子參考工具書達36種。

　　●Knovel( http://www.knovel.com )︰整合了近30家出版社的519種工具書，並包括7種網路數據分析工具。

　　●Book24x7（ http://www.books24x7.com ）︰以訊息及商企業所有人題為主，約有60家圖書供貨商。

　　●Questia（ http://www.questia.com ）︰收錄人文社會科學主題之圖書及期刊，主要提供研究論文寫作相關之圖書、期刊數據，共有200多家供貨商。

2.1.4電子報紙早在20世紀80年代末期，一些報紙就被數字化並存儲到CD-ROM上。90年代互聯網出現後，它們自然也出現下網路和數字圖書館中。

　　EBSCO ( http://www.ebsco.com ) 、ProQuest Information and Learning( http://www.il.proquest.com )和LexisNexis（ http://www.lexisnexis.com ）等數據庫商的產品中都包含大量的電子報紙。

　　像電子期刊一樣，電子報紙與其印刷版不一定相同，電子版通常會提供更多的特色內容，如增加了到相關新聞條目的鏈接。

　　一些數字圖書館（通常是專業圖書館）為用戶提供電子新聞剪報服務。儘管電子新聞剪報服務需要大量的人力，但相比紙本的剪報服務還是省時省力多了。此類服務的優點是︰在網上即時獲取新聞剪報訊息；可獲取訊息全文及圖表等；有方便快捷的檢索工具；用戶可即時回饋；自由下載及列印。

2.1.5電子博碩士論文博碩士研究成果是重要的訊息資源。成立於1938年的美國大學縮微品公司（UMI）最早是為了在戰爭時期儲存大不列顛博物館的學術珍品，隨後，其創辦人Eugene Power就開始在縮微膠捲上儲存學位論文。現下，ProQuest Information and Learning公司是美國的國家圖書館──國會圖書館指定的收藏全美國博碩士論文的分館，也是加拿大國家圖書館指定的收藏加拿大全國博碩士論文的機構。該公司的產品──ProQuest Digital Dissertations（簡稱PQDD，http://wwwlib.global.umi.com/dissertations ）是目前世界上最大的博碩士論文文摘數據庫。PQDD現收錄超過200多萬條記錄，涵蓋了從1861年獲得透過的全世界第一篇博士論文（美國）到本年度本學期獲得透過的博碩士論文訊息。數據庫提供每篇論文的題錄或文摘，對於1997年以後出版的論文，ProQuest公司能提供其電子版的副本。

　　目前很多學術機構開始關注電子學位論文資源，並將它們作為數字圖書館館藏的一個組成部分。為了推展電子博碩士論文的發展以加速研究生研究成果的利用，美國的維吉妮亞科技大學創立了“博碩士論文網路數字圖書館”(Networked Digital Library of Theses and Dissertations，簡稱NDLTD, http://www.ndltd.org )。NDLTD是由美國國家自然科學基金支援的一個網上學位論文共建共享項目，為用戶提供免費的學位論文文摘，還有部分可獲取免費的學位論文全文（根據作者的要求，全文分為無限制下載、有限制下載、不能下載幾種模式）。目前，全球有195家大學（包括7個聯盟）和28個研究所加入了NDLTD。

　　與PQDD相比，NDLTD學位論文庫的主要特點就是學校共建共享，可以免費獲取。另外，由於NDLTD的成員館來自全球各地，所以覆蓋的範圍比較廣，有德國、丹麥等歐洲國家和香港、台灣等地區的學位論文。但是由於文摘和可獲取的全文都比較少（截止到2003年底，有文摘7萬條，全文3萬篇），NDLTD適合作為國外學位論文的補充資源。

　　其他機構建立的電子博碩士論文資源主要有以下6個︰

　　●澳洲電子學位論文庫 (Australian Digital Theses Program，簡稱ADT，http://adt.caul.edu.au )。

　　●柏林Humboldt 大學電子學位論文方案 ( http://dochost.rz.hu-berlin.de/epdiss/index_en.html  )。

　　●芬蘭赫爾辛基科技大學電子學位論文庫 ( http://lib.hut.fi/Diss/ )。

　　●加拿大麥姬兒大學蒙特婁電子論文庫 ( http://digital.library.mcgill.ca/ethesis/ )。

　　●瑞典 Uppsala大學電子論文庫 ( http://publications.uu.se/theses/ )。

　　●德國網上論文資源（ http://deposit.ddb.de/ ）。

2.1.6電子檔案越來越多的地區和國家檔案館逐步從提供目錄、索引，過渡到提供數字化檔案供用戶免費訪問。

　　全球性的電子檔案計畫有聯合國教科文組織(UNESCO)自1992年發起的“世界記憶”項目( http://www.unesco.org/webworld/mdm/en/index_mdm.html )， 旨在儲存和傳播世界各種語言、文化和民族的檔案資源，包括33個國家的68個項目。在同一系統中還包括聯合國教科文組織和國際圖書館協會聯合會(IFLA) 合作的 DigiCol項目( http://www.unesco.org/webworld/digicol )，此項目選擇並數字化了一些世界各國珍貴的歷史文化資源。

　　一些國家級的電子檔案計畫目前主要有︰

　　●英國國家檔案 ( http://www.nationalarchives.gov.uk )︰跨越了1 000多年的英國歷史，內容豐富，包括英國土地志、古籍書刊、繪畫、圖片、政府文獻等各種資源。

　　●美國遺產虛擬檔案計畫 ( http://sunsite.berkeley.edu/amher/ ︰由美國幾所知名大學合作，旨在促進對美國歷史和文化文獻的整理和利用。

　　●加拿大國家圖書檔案 ( http://www.collectionscanada.ca/index-e.html )︰包括16世紀至今的有歷史文化價值的電子檔案資源。類型有電影、記錄片、圖片、照片、地圖、藝術珍品、錄音資料、古籍書刊、政府出版物等。

2.2二次文獻和書目訊息

　　很多情況下，數字圖書館中有些資源還沒有或由於特殊原因無法數字化。所以儘管有了電子全文資源，二次文獻在數字圖書館中仍佔有重要地位。例如英國的兩大數字圖書館項目──Burney項目（對1800年以前的報紙進行數字化，http://www.bl.uk/collections/burney.html ）和Cantersbury Tales計畫（掃描所有1500年前的手稿，http://www.cta.dmu.ac.uk/projects/ctp/ ），兩者的基礎都是二次文獻和書目。

2.2.1線上檢索目錄線上檢索目錄是數字圖書館的重要訊息資源之一。日本的電子圖書館計畫就是一個使用範例，其內容有線上檢索目錄、日本期刊題名索引目錄。

　　數字圖書館除了包括內部線上檢索目錄外，還可以鏈接以下外部線上檢索目錄︰

　　●歐洲國家圖書館通訊閘（Gabriel）──包括歐洲41個國家圖書館的網址及線上檢索目錄（http://portico.bl.uk/gabriel/index.html ）。

　　●線上索引（LIBDEX）──包括全球1 8萬個線上檢索目錄。

　　●虛擬聯合目錄──透過Z39.50協議和適當的軟體，建立特定區域或特定主題的線上檢索目錄共享。

2.2.2文摘索引數據庫20世紀70-80年代，很多文摘索引出版物（如藝術文摘、化學文摘、工程索引、心理學文摘）開始有了計算機數據庫形式，互聯網出現後便產生了網路版數據庫。

　　目前國外一些主要的文摘索引數據庫有︰BIOSIS（生物科學）、Chemical Abstracts（化學）、Ei COMPENDEX（工程學）、EMBASE（生物醫學和藥學）、ERIC（教育）、INSPEC（物理，電子工程，計算機技術）、Medline（醫學）、PsycInfo（心理學）、Science Citation Index（自然科學）等。

　　國外著名的綜合型文摘索引數據庫有︰DIALOG（包括近600個線上數據庫）、CSA（包括70個文摘索引數據庫）、OCLC First Search（包括72個數據庫），等等。

2.3多媒體資源

　　數字圖書館中出現的多媒體資源的主要類型有︰獨立靜態圖像（如照片、圖片），動態圖像（如電影、錄像），錄音資料及動畫。一些國家博物館、圖書館和檔案館已在致力收藏國家音像資料，如國家電視台和廣播台的錄像、錄音資料等。ScreenSound Australia（澳洲音像數字圖書館，http://www.screensound.gov.au ）收錄了一些記錄片、電影、電視新聞時事、音樂、口述歷史、演說等音像資源。很多博物館、藝廊和圖書館都將其收藏的圖像資料、文化遺產圖片數字化，使更多人能觀賞到這些珍品。

　　演說和音樂等內容也是數字化的一個熱點。學術性數字圖書館的資源重點是演講錄音資料及其他教學相關資料。英國的Richmond公共圖書館提供電子聲音圖書，這對有視覺障礙的用戶來說是一大福音。British Library Sound Archive（大英圖書館錄音檔案，http://www.bl.uk/collections/sound-archive/nsa.html ）有從世界各地收集的約100萬張唱片，18 5萬張盒卡帶及其他錄音資料。到2006年，大部分資料將被數字化並可從網上訪問，內容有音樂、口述歷史、野生生物錄音等。

2.4網頁、通訊閘

　　萬維網虛擬圖書館（ http://www.vlib.org ）是最早建立的有關學科主題的網站。其內容由一些自願參加的專家學人挑選編輯。很多數字圖書館包括一些對相關網站的鏈接，如英國20世紀90年代始創的eLIB計畫，其中的一個項目就是建立各種學科主題（生物醫學、工程和社會科學等）的網頁。此項目的成果為Resource Discovery Network（資源探索網，簡稱RDN)， ( http://www.rdn.ac.uk )，所整理的網站記錄由70多家教育研究機構的專家精選、索引和描述。

　　RDN還加入了Renardus計畫 ( http://www.renardus.org )，該計畫旨在為歐洲高等教育的教學研究提供專家推薦的高品質網站索引。此計畫內的其他網站有︰

　　●虛擬英美文化語言指南 ( http://www.anglistikguide.de/ )。

　　●德國農業訊息網路 ( http://www.dainet.de )。

　　●丹麥電子研究圖書館 ( http://deff.dk/ )。

　　●荷蘭電子主題服務 ( http://www.kb.nl/dutchess )。

　　●芬蘭虛擬圖書館 ( http://www.jyu.fi/library/virtualalikirjasto/engvirli.htm ) 。

　　●地球科學指南 ( http://www.geo-guide.de/ )。

　　●英美歷史指南 ( http://www.historyguide.de/ )。

　　●數學指南 ( http://www.mathguide.de/ )。

　　●北歐森林、畜牧、農業訊息通訊閘 ( http://novagate.nova-university.org/ )。

3　結語

　　綜上所述，國外數字圖書館及資源建設發展較早，已形成一定規模。相比較而言，我國數字圖書館及資源建設起步較晚，對數字圖書館的認識程度、建設資金、技術力量等都與發達國家存在一定差距。在這個全球化的時代裡，數字圖書館也正成為全球性的工程。因此，一方面，我們應改善自身建設條件，充分借鏡國外的經驗並根據我國具體情況建設有中國特色的數字圖書館；另一方面，我們也需要積極跨出國門，加強與世界各國的合作，共建共享，融入全球數字圖書館建設的大潮中。

　　注︰本文系深圳大學中青年科研啟動基金項目“國內外數字圖書館資源研究”（項目編號︰020924）研究成果之一。
