臺灣網站典藏庫
2006年起國立臺灣大學圖書館於規畫「機構典藏」計畫時特別將「網站典藏」（Web Archives）並列入計畫的一環，並馬上著手系統開發及網站典藏範圍與政策的設定，致力於「選擇（select）」、「蒐集（collect）」、「保存（preserve）」原始性網頁資料，以期為臺灣善盡保資產之責任，並提供檢索服務以滿足當代與未來世代研究發展之需求。 臺大圖書館網站典藏庫(以下簡稱NTUWAS)目標如下： 1. 提供網頁典藏(Web Archive)機制； 2. 紀錄網站發展的歷程； 3. 收藏網路記憶中的臺灣紀錄，提供未來學術研究的參考。

臺灣網站典藏庫．NTU Web Archive System

留存 網站發展在時間軸上的刻痕 讓「曾經」停頓更久…

::: 彌補須臾衍生的空白 :::

2006年起，臺大圖書館機構典藏計畫即規劃、建置網站典藏系統，並逐步進行系統測試及典藏工作。歷時兩年，2008年四月，「臺灣網站典藏庫」（NTU Web Archive System，NTUWAS）正式上線。臺灣網站典藏庫選擇、蒐集、保存原始網頁資料，善盡保存臺灣網站數位資產的責任。此外，提供主題瀏覽、關鍵字檢索等功能，以滿足當代與未來世代研究發展之需求。
::: 精粹網路記憶的臺灣 :::
臺灣網站典藏庫綜存網站新舊版本，記錄臺灣地區人民和國家的發展歷程，並觀照同時期國際社會的變化脈絡，讓臺灣印象能持續鮮活於線上。
::: 集結各方智慧的力量 :::
臺灣網站典藏庫提供網站典藏（Web Archive）機制，期望號召各大學圖書館、相關單位參與，共同擴充網站資料收錄範圍，規畫蒐集臺灣地區以外各類網路資源，豐富網站典藏的多元面向。此外，歡迎每一位使用者分享、推薦更多值得蒐藏的網站，讓臺灣網站典藏庫能集結各方的力量，更上層樓。

臺大機構典藏 NTUR    臺灣機構典藏 TAIR  2007.06.10    機構典藏計畫網站
為了讓學校學術研究成果可以保存並方便運用，教育部補助國立台灣大學辦理「建置機構學術成果典藏計畫」，未來並擬建置台灣地區各大學及研究機構的學術成果典藏系統雛型，以期規劃建立共通使用平台。 自九十五年度起，教育部補助國立台灣大學辦理這項學術成果寶藏計畫，現已完成台大機構典藏系統雛型 ， 該系統徵集台大師生學術成果共三萬零四百四十四筆，其中一萬三千七百一十篇為全文數位檔案。 所謂機構典藏（Institutional Repository，簡稱IR）是一個機構（大學）將本身的研究產出，如期刊及會議論文、研究報告、投影片、教材教案等以數位的方法保存並建立網路平台，提供查詢與使用的管道，收錄資料以全文為主，並建立全文檢索機制，可以視為研究產出為主要內容的蒐尋引擎(search engine)。 教育部強調，機構典藏並不是要取代期刊的發表，而是增加一個研究成果被使用的管道。目前台灣學術界要用本國的學術研究成果比用英文學術資源還不易，且本國的學術成果被使用率甚至不及外文來的方便。 有鑑於此，建立學校學術成果研究歷程的完善保存機制，呈現整體的研究實力與成果，增加論文研究成果曝光管道，提高被引用率及知名度是重要工作。 另外，這項計畫也整合建置台灣機構典藏系統，簡稱TAIR， 未來也將開放相關學術研究成果，免費供各大學院校建置機構典藏系統參考。 教育部並會持續推動機構典藏觀念的重要性，提供建置系統的標準與流程，供各校參考。

  學術資源網
 大學學術的經營，網路科技扮演著舉足輕重的角色。藉由網路的傳播展現學術表現、研究成果並使知識得以被公開取得，進而增加學術機構的能見度並發揮其影響力，當為今日大學的重要課題，因此學術網站經營的重要性與日俱增。「學術資源網」蒐集各校學術檔案資源，希望儘力呈現本校學術優質人才、研究能量、著作及學術檔案等，並配合網站健檢及網站優化等計畫，進而提昇本校網站在國際的能見度。
