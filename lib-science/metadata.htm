Metadata Encoding and Transmission Standard (METS) Official Web Site
目前於美國紐約大學Elmer Holmes Bobst圖書館，擔任數位圖書館研發團隊領導人的Jerome McDonough日前公開發表beta版之METS( Metadata Encoding and Transmission Standard, METS) XML schema，期能針對數位圖書館物件的編碼敘述、管理與元資料(metadata)建構提供一以XML為基礎之架構。METS係由聯邦數位圖書館(Digital Library Federation)所發起與研發，現由美國圖書館代表大會網際網路發展與MARX標準辦公室(Network Development and MARC Standards Office of the US Library of Congress)負責維護工作。
由METS網站資料顯示，公佈的METS 文件主要包含四個章節：1. 描述性元資料(Descriptive Metadata)﹔2. 管理性元資料(Administrative Metadata)﹔3. 檔案群組(File Groups)﹔4. 結構性地圖(Structural Map)﹔未來METS除可作為儲存庫與數位圖書館物件間資料交換的標準機制外，另可當作數位圖書館物件於區域儲存、取出與展現時所需之編碼機制﹔研發團隊現針對METS XML schema設計之議題徵求圖書館社群意見，若讀者對METS XML schema有任何意見，可於2001年8月31日前，透過Listserver將意見寄給前述研發團隊，研發團隊預期於九月份之會議中進行修正討論﹔或可透過以METS研發社群為對象的METS論壇機制，表達對METS XML schema的看法。
